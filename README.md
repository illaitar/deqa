# DeQA

Метрика качества устранения размытия. На вход берёт две картинки: размытый кадр и результат работы метода. Резкий эталон не нужен, поэтому метрику можно считать на обычном видео, где эталона нет.

Чем больше значение, тем лучше результат. Шкала та же, что у субъективных оценок, на которых метрика обучалась (модель Брэдли-Терри по попарным сравнениям).

## Как устроена

Обе картинки проходят через один и тот же ResNet, предобученный на ImageNet. С четырёх уровней сети берутся карты признаков, на каждом уровне считается разность между результатом и входом и её квадрат. Дальше пространственное внимание выбирает области, где резкость поменялась, и по ним карта сворачивается в вектор.

К этим векторам добавляются девять классических признаков из предыдущей версии метрики (BASED): лапласиан, спектр без низких частот, фильтр Габора, линии Хафа, HOG, SSIM по YUV с весами 6:1:1, Собель, LBP по карте границ и повторное размытие. На мелких фрагментах 128×128 они помогают, сеть там ведёт себя менее устойчиво.

Всё вместе идёт в голову из двух полносвязных слоёв. Код сети в `deqa/model.py`, признаков в `deqa/features.py`.

## Установка

```
pip install -r requirements.txt
```

Проверено на Python 3.11. Работает на CUDA, на Apple Silicon через MPS и на процессоре.

## Использование

Одна пара из консоли:

```
python predict.py blur.png result.png --weights deqa.pth
```

Из кода:

```python
import cv2
from deqa import DeQAMetric

metric = DeQAMetric("deqa.pth")
score = metric(cv2.imread("blur.png"), cv2.imread("result.png"))
```

Картинки должны быть одного размера. Классические признаки считаются на процессоре и занимают около 0.1 с на пару 512×512, это заметно дольше самой сети.

Весов в репозитории пока нет, их нужно обучить самому (см. ниже).

## Данные

Формат такой же, как в BASED:

```
crops/
  scene_1/
    real_blur.png     размытый вход
    nafnet.png        результаты методов, имя файла = имя метода
    restormer.png
  scene_2/
    ...
subj.csv              колонки video, method, value
```

`video` это имя папки сцены, `method` имя файла без расширения, `value` субъективная оценка. Строки с `method = real_blur` пропускаются.

## Обучение

```
python train.py --crops crops --subj subj.csv --out runs/deqa
```

Лосс состоит из MSE по оценке и попарной ранговой части. Ранговая часть считается только между результатами одной сцены: оценки Брэдли-Терри строятся для каждой сцены отдельно, и сравнивать их между сценами напрямую нельзя. Поэтому батч собирается из сцен, по `--k` методов на каждую.

Кодировщик дообучается с шагом в десять раз меньше, чем у остальной сети. Обучение идёт на кропах 128×128, проверка на целых фрагментах. Проверочные сцены откладываются целиком (`--val-frac`), лучшая по SRCC эпоха сохраняется в `runs/deqa/deqa.pth`.

Классические признаки при первом запуске считаются для всей выборки и кладутся в `features.npz` рядом с весами.

## Оценка

```
python evaluate.py --weights runs/deqa/deqa.pth --crops crops_test --subj subj_test.csv
```

Печатает коэффициенты Пирсона, Спирмена и Кендалла: по всем парам сразу и в среднем по сценам. Ключ `--save out.csv` сохраняет оценку для каждой пары.
